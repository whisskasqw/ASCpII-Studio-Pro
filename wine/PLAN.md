# Plan: «Vinum Fortis», калькулятор крепления вина

> Короткий план для исполнителя (Sonnet). Выполнить целиком за один заход, ничего не уточняя.
> Язык интерфейса: русский. Сборки нет, чистый HTML/CSS/JS. Всё лежит в `wine/`, остальной репозиторий не трогать.

## 1. Цель
Пользователь выбирает конкретное вино (тип, сорт, стиль) или вводит своё, задаёт параметры и целевой стиль/крепость.
Сайт считает, **сколько и чего добавить** (спирт/дистиллят, сахар, при желании концентрат сусла) и **предсказывает параметры** готового креплёного вина.

## 2. Файлы
```
wine/
  index.html   разметка, подключает data.js, calc.js, app.js
  styles.css   дизайн
  data.js      справочники (window.WINE_DATA), без логики
  calc.js      чистые функции расчёта (UMD: window.WineCalc + module.exports для node)
  app.js       UI: формы, пресеты, рендер результатов, localStorage для последнего ввода
  calc.test.js тесты на node:test (запуск: node --test wine/)
  README.md    как запустить: `python3 -m http.server 8000` → http://localhost:8000/wine/
```

## 3. Справочники (data.js)
**Вина** (≥ 30 записей): `id, name, color(red|white|rose|orange), grape, region, abv, sugar g/L, ta g/L (по винной к-те), pH, va g/L, freeSO2 mg/L, totalSO2 mg/L, extract g/L (приведённый), hue` (цвет для бокала).
Например: Каберне Совиньон, Мерло, Саперави, Пино Нуар, Сира, Тинта Роривш, Турига Насьонал, Гренаш, Мальбек, Красностоп, Шардоне, Совиньон Блан, Рислинг, Ркацители, Алиготе, Мускат белый, Мускат розовый, Паломино, Педро Хименес, Серсиаль, Мальвазия, Вердельо, Грилло, Кагор (Моррастель), Шираз, Розе Гренаш, Цимлянский чёрный, Бастардо магарачский, Кокур, «своё вино».
Отдельный режим **сусло/бродящее сусло**: сахар сусла (г/л или °Brix), текущая плотность или % сброжённости.

**Спирты для крепления**: ректификат «Люкс» 96.4%, винный спирт 96%, виноградный дистиллят 70%, коньячный спирт 62%, aguardente 77%, бренди 40%, своё значение. Поле: `abv, sugar=0, ta=0, density`.

**Целевые стили** (диапазоны ABV / сахар / подсказки):
Портвейн Ruby/Tawny (19–22%, 80–120 г/л), Белый портвейн (19–20%, 40–100), Херес Fino/Manzanilla (15–15.5%, <5), Amontillado (16–17.5%, <5), Oloroso (17–20%, <5), Cream (15.5–22%, 115–140), PX (15–22%, >212), Мадера Sercial/Verdelho/Bual/Malmsey (17–22%; 0–65 / 49–78 / 78–96 / >96), Марсала Secco/Semisecco/Dolce (≥17–18%; <40 / 40–100 / >100), VDN Muscat (≥15%, ≥100–125), Кагор (16%, 160 г/л), Крепкое (ГОСТ 32030: 17–21%, ≤ 30–60), Десертное/ликёрное (15–17%, 100–200).

## 4. Расчёт (calc.js), всё в чистых функциях с юнит-тестами
Вход: `V_w` (л), параметры вина, спирт `a_s`, цель `A` (% об.), цель сахара `S_t` (г/л), режим `wine | must` (мутаж).

1. **Спирт (уравнение баланса, «квадрат Пирсона»):**
   `V_s = V_w · (A − a_w) / (a_s − A)`; с учётом сахара/сусла, добавляемых до спирта, итерировать (3–5 итераций), пока A и S не сойдутся.
2. **Контракция водно-спиртовой смеси:** поправка объёма `V_f = (V_w + V_s + V_sugar) · (1 − k)`, где `k` из табличной интерполяции (≈0.5–1.5% для 15–22% об.; таблица 6–8 точек в data.js). Показать «без контракции / с контракцией».
3. **Сахар:** сахароза добавляет ~0.625 л объёма на 1 кг (уд. объём 0.63). `m_sugar = S_t·V_f − S_w·V_w` (решать совместно с п.1). Альтернатива: РКС (концентрат сусла 65 °Brix ≈ 860 г/л сахара).
4. **Мутаж (режим must):** вход: сахар сусла S0, % сброжённости p. Текущий сахар `S = S0(1−p)`, текущий спирт `a = S0·p / 16.83` (г/л на 1% об.; коэффициент в настройках 16.5–17.5). Дальше пп.1–3. Подсказка: брожение прекращается при ≥ 15–16% об.
5. **Прогноз остальных параметров** (разбавление `d = V_w/V_f`):
   - ТК `ta_f = ta_w·d`; ЛК `va_f = va_w·d`; SO₂ своб./общ. ×d; приведённый экстракт ×d (+ без сахара);
   - pH: `pH_f ≈ pH_w − log10(d)·0.35` (буферная аппроксимация, отметить как оценку);
   - плотность при 20 °C: `ρ ≈ 0.9982 − 0.00125·ABV + 0.000375·S + 0.0004·extract_nonsugar` (г/см³), показать также в °Brix/Боме;
   - калорийность на 100 мл: `ABV·0.789·7 + S/10·4`;
   - сахарно-кислотный индекс `S/ta`, «индекс спиртуозности» и категория по сладости (сухое/полусухое/полусладкое/сладкое/ликёрное);
   - **соответствие стилю:** зелёный/жёлтый/красный по каждому параметру из диапазонов цели + текстовые рекомендации (напр. «кислотность низкая для мадеры, +1 г/л винной к-ты»).
6. **Валидация:** `a_s > A > a_w`, все значения ≥ 0, понятные ошибки на русском. Округления: литры 2 знака, граммы целые.
7. **Тесты (≥ 10):** пример 10 л, 12% → 19% ректификатом 96.4% ≈ 1.04 л; нулевая разница; сахар до 100 г/л; мутаж; невалидный ввод; pH/ТК при разбавлении; классификация стиля.

## 5. UI (app.js + index.html)
Одна страница, три шага в виде «бочек/этапов»:
1. **Вино**: поиск-селект с группами по цвету, карточка сорта; все поля редактируемые, кнопка «сбросить к сорту». Переключатель «готовое вино / бродящее сусло».
2. **Крепление**: объём, спирт (селект + своё), целевой стиль (селект, подставляет A и S по середине диапазона) с ручными ползунками A и S, опции: учитывать контракцию, сахар/РКС.
3. **Результат** (обновляется live, без кнопки): «рецепт» (сколько л спирта, кг сахара, итоговый объём, порядок действий), таблица «было → стало», бейджи соответствия стилю, оценка выдержки/рекомендации.
Плюс: экспорт рецепта в печать (`window.print` со стилем print), сохранение в localStorage, переключение л/мл.

## 6. Дизайн: «погреб и этикетка»
- Палитра (CSS-переменные на `:root`): бордо `#5a0f1f`, гранат `#8c1c2c`, пергамент `#f3e9d7`, дуб `#6b4a2b`, латунь `#b08a3e`, чернила `#241a17`. Тёмная тема: «ночной погреб» (`#1a0f10` фон, пергамент текст).
- Шрифты Google Fonts: **Cormorant Garamond** (заголовки, курсив для сортов), **Inter** (UI), **JetBrains Mono** с tabular-nums для цифр.
- Фон: тонкая текстура пергамента через CSS-градиенты + SVG-шум (inline), «винные кольца» от бокала как декор в углах.
- Главный герой: **SVG-бокал** справа, жидкость меняет уровень и цвет (`hue` вина, темнее/янтарнее при большем сахаре и стиле tawny/мадера), плавная анимация `transition`. Под ним шкала крепости как «ареометр».
- Результат оформлен как **винная этикетка**: рамка-гравюра (двойной бордюр), название стиля, сорт, «Vol. 19.0 %», «Sugar 100 g/L», печать-медальон латунного цвета.
- Карточки шагов: бумага с мягкой тенью, номера шагов римскими цифрами I · II · III.
- Адаптив: на ширине < 860px бокал над формой, отступы 16px, без горизонтального скролла. `prefers-reduced-motion` уважать.
- Без эмодзи и фиолетовых градиентов; иконки (бочка, гроздь, бутылка) inline SVG в одном стиле линий.
