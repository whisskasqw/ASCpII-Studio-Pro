# Vinum Fortis

Калькулятор крепления вина: выбираете сорт (или вводите свой анализ) и целевой стиль, а сайт считает, сколько спирта и сахара (или концентрата сусла) добавить, и прогнозирует параметры готового вина.

## Запуск
```bash
cd ASCpII-Studio-Pro
python3 -m http.server 8000
# открыть http://localhost:8000/wine/
```
Можно открыть и просто `wine/index.html` двойным щелчком, сборка не нужна.

## Тесты
```bash
node --test wine/calc.test.js
```

## Что считается
- Спирт: баланс этанола (квадрат Пирсона) с итеративной поправкой на контракцию водно-спиртовой смеси.
- Сахар: сахароза (с учётом её объёма 0.63 л/кг) или ректифицированный концентрат сусла.
- Мутаж: состояние бродящего сусла по сахару и сброжённости (16.83 г/л сахара на 1 % спирта), поиск момента мутажа без подсластки.
- Прогноз: кислотность, pH (оценка), SO₂, экстракт, плотность, °Brix, Боме, калорийность, СКИ, категория сладости, соответствие стилю и рекомендации.

## Разделы
- **Калькулятор.** Подбор доз под цель или проверка своих доз; готовое вино или бродящее сусло (мутаж) с графиком «момент мутажа → сахар и доза спирта» и автоподбором точки мутажа; сравнение всех спиртов; розлив и себестоимость партии, литра и бутылки; копирование рецепта, ссылка на расчёт, печать.
- **Мастерская.** Купаж двух вин, подкисление и раскисление, сульфитация по молекулярному SO₂, разведение спирта водой с контракцией, ареометр (°Brix, Боме, Эксле, потенциальный спирт, шаптализация), справка по стилям.
- **Журнал партий.** Сохранение расчётов в браузере, открытие, ссылка, экспорт в JSON и CSV (для Excel), импорт.

Сайт работает офлайн: после первого открытия по http(s) файлы кэшируются, его можно установить как приложение.

Значения сортов и стилей типовые, ориентировочные. Для точного результата вписывайте данные лабораторного анализа.
